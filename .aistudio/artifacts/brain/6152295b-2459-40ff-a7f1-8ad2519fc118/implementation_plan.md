# ترقية الواجهة وسلايدر العروض وسجل طلبات فيربيز — دلمون للدواجن (dawajen.bh)

تحديث المتجر الإلكتروني لشركة دلمون للدواجن بتضمين سلايدر عروض ترويجي تفاعلي، وربط حساب المستخدم بتسجيل الدخول بحساب Google عبر Firebase للاطلاع على سجل الطلبات والفواتير السابقة، مع حصر شبكة المنتجات في تشكيلات الدواجن الطازجة اليومية.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد القرارات التالية بناءً على اختياراتك المباشرة:
> - **سلايدر العروض الترويجي**: تحويل البانر العلوي الثابت إلى سلايدر متحرك غني بالتنقل السلس والشرائح الترويجية (عرض دجاج المزرعة دلمون، عرض بوكس أرياف التوفيري الكبير، وعروض المواشي والذبائح الطازجة).
> - **تسجيل الدخول وحساب المستخدم**: تفعيل أيقونة الحساب في الترويسة لتدعم تسجيل الدخول عبر Google Authentication باستخدام Firebase، مع نافذة جانبية منبثقة تعرض الملف الشخصي وسجل طلباتي السابقة مع تفاصيل الدفع وحالة التوصيل.
> - **حصر شبكة المنتجات**: تركيز شبكة المنتجات والتصفية السفلية بالكامل على أصناف الدواجن الطازجة اليومية (دجاج كامل، صدور وفيليه، أجنحة، أفخاذ، دجاج متبل، مفروم)، دون تشتيت الزائر بمنتجات المواشي في شبكة التسوق السريعة.

---

### 1. Overview & Core Concept

- **طبيعة الميزة**: تجربة تسوق بحرينية سريعة تجمع بين إبراز العروض الموسمية والتوفيرية في صدارة الصفحة عبر سلايدر احترافي، وتمكين العملاء من حفظ بياناتهم ومراجعة طلباتهم المدفوعة عبر بنفت من خلال حساب Google موثق.
- **الجمهور المستهدف**: الأسر والعملاء في كافة محافظات مملكة البحرين الراغبون في طلب الدواجن الطازجة يومياً مع التوصيل المبرد خلال 40 دقيقة، مع سهولة مراجعة فواتيرهم السابقة.
- **القيمة الأساسية**: رفع معدل التحويل التسويقي عبر العروض المرئية الجذابة، وإعطاء مصداقية وأمان عالي بتمكين تسجيل الدخول ومتابعة حالة الطلبات المخزنة في Firestore.

---

### 2. User Experience & Visual Design

#### مسارات المستخدم التفاعلية (User Flows)
1. **استعراض سلايدر العروض**:
   - الشريحة الأولى: دجاج المزرعة من دلمون (طازج يومياً، يصل لبابك، زر تسوق الآن).
   - الشريحة الثانية: عرض أرياف الخاص (صندوق 10 دجاجات + 5 أطباق صدور + أرز بسمتي 10 كغ بسعر 5 د.ب والتوصيل مجاناً).
   - الشريحة الثالثة: ذبائح ومواشي طازجة (اختيار وتقطيع وتوصيل مبرد لباب المنزل).
   - تحكم كامل: أزرار السابق/التالي، مؤشرات نقاط سفلية (Bullets)، وتوقف تلقائي عند تمرير المؤشر (Pause on hover).
2. **تسجيل الدخول بحساب Google**:
   - النقر على أيقونة المستخدم (User) في الترويسة.
   - إذا كان الزائر غير مسجل: تفتح نافذة منبثقة أنيقة تتيح تسجيل الدخول السريع بضغطة زر واحدة عبر Google Popup.
   - إذا كان مسجلاً: تظهر بطاقة المستخدم (الاسم، البريد، الصورة الرمزية)، مع زر "طلباتي" لعرض تاريخ الطلبات المخزنة في Firestore، وزر تسجيل الخروج.
3. **عرض سجل الطلبات (Order History)**:
   - جلب الطلبات من Firestore تلقائياً بحسب رقم الهاتف أو البريد.
   - بطاقة لكل طلب توضح: رقم الطلب (`BH-XXXXXX`)، التاريخ والوقت، إجمالي المبلغ، حالة الطلب (تم الاستلام / قيد التجهيز / جاري التوصيل)، والمنتجات المطلوبة.
4. **تصفح وشراء الدواجن الطازجة**:
   - شبكة المنتجات مقتصرة حصرياً على الدواجن اليومية مع الأوزان (600 جم، 800 جم، 1000 جم، 1200 جم، إلخ) وإضافة فورية للسلة.

#### الهوية البصرية والنظام اللوني
- **لوحة الألوان المعتمدة (60-30-10)**:
  - 60% خلفية ناصعة ومريحة (`#f8f9fa` مع لمسات رمادية هادئة).
  - 30% أسطح كروت المنتجات البيضاء النظيفة بحواف ناعمة وفواصل دقيقة دون تكرار أو مبالغة.
  - 10% اللون الأحمر القرمزي الرسمي لدلمون (`#c8102e` و `#b91921`) للأزرار النشطة وشارات السلة وشريط العروض، مع الأسود الفحمي للأزرار الداكنة.
- **الطباعة والتنسيق**:
  - خط تجوال (Tajawal) العربي الرسمي بوزن 800 للعناوين البارزة و 500 للنصوص.
  - أرقام أسعار جدولية متسقة (`font-sans tabular-nums`).
- **الحركة والاستجابة**:
  - انتقالات سلايدر ناعمة خلال 300ms دون وميض.
  - حوارات منبثقة (Modals) بحجم متناسق ومطابقة لمعايير WCAG.

### 3. Key Product Decisions & Trade-Offs

- **القرار 1: اعتماد سلايدر عروض ترويجي بدل البانر الفردي**:
  - *النهج*: سلايدر متعدد الشرائح يدعم التبديل اليدوي والتلقائي (كل 5 ثوانٍ)، يدمج هوية دلمون وعروض أرياف التوفيرية والمواشي.
  - *السبب*: إبراز باقات التوفير الكبرى فور فتح الموقع دون الحاجة للتمرير لأسفل، مع الحفاظ على سرعة تصفح الدواجن اليومية.
  - *البديل المستبعد*: تكديس عدة بنرات عمودية فوق بعضها، مما يرهق المستخدم ويزيد مساحة التمرير.

- **القرار 2: دمج تسجيل الدخول بجوجل عبر Firebase Auth في الترويسة**:
  - *النهج*: استخدام `signInWithPopup(auth, googleProvider)` مع حفظ حالة المستخدم وإظهار سجل الفواتير مباشرة من مجموعة `orders` في Firestore.
  - *السبب*: سرعة وسلاسة لا تطلب من العميل كتابة كلمات مرور جديدة، وربط حقيقي بالسحابة التي تمت تهيئتها.
  - *البديل المستبعد*: النماذج المعقدة بكلمات المرور والتأكيد عبر الإيميل التي تعطل سرعة الشراء.

- **القرار 3: حصر الكتالوج الرئيسي بالدواجن الطازجة فقط**:
  - *النهج*: تصفية شبكة المنتجات لاستبعاد بطاقات المواشي المباشرة وجعلها تقتصر على الدجاج الكامل، القطع، الأجنحة، المفروم والمتبل، مع إبقاء عروض المواشي ترويجياً فقط في السلايدر.
  - *السبب*: تنفيذ مباشر لاختيارك الصريح بالتركيز على الدواجن اليومية لمنع أي ارتباك في أوزان وأسعار الذبائح.

```
┌─────────────────────────────────────────────────────────────┐

│  Header (Brand + Nav + Search + Wishlist + Cart + AuthBtn)  │
├─────────────────────────────────────────────────────────────┤
│  Promotional Hero Carousel (Delmon / Aryaf / Mawashi)       │
├─────────────────────────────────────────────────────────────┤
│  Shop Layout:                                               │
│  ┌───────────────────────┐   ┌────────────────────────────┐ │
│  │ Fresh Chicken Catalog │   │ Filter Sidebar (Price/Sort)│ │
│  │ (Whole, Cuts, Fillet) │   └────────────────────────────┘ │
│  └───────────────────────┘                                  │
├─────────────────────────────────────────────────────────────┤
│  Modals & Drawers:                                          │
│  - User Profile & Order History Drawer (Firebase Auth/DB)   │
│  - Weight Selection Modal (400g - 1200g)                    │
│  - Benefit Payment Gateway Simulator                        │
└──────────────────────────────┬──────────────────────────────┘
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
   Firebase Authentication               Cloud Firestore (europe-west1)
   - Google Sign-In                      - /orders/{orderId}
   - User State & Avatar                 - /customers/{phone}
```

#### مخطط البيانات وحالة المتجر
- **Firebase Auth State**: تتبع `currentUser` (الاسم، البريد، الرمز التعريفي UID، الصورة الرمزية).
- **Orders Collection** (`/orders/{orderId}`):
  - الاستعلام عن طلبات العميل بناءً على `orderId` المحفوظة محلياً أو المقترنة برقم هاتف العميل.
  - قفل الطلبات لمنع تعديلها بعد الدفع، وعرض رقم الطلب، المبلغ، وحالة السداد ببنفت.
- **سلايدر العروض**:
  - حالة الشريحة الحالية (`currentSlide: 0..2`).
  - مؤقت تشغيل تلقائي ذكي يُلغى فور ملامسة المؤشر (hover).
